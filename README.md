## 部署與更新

建議雙擊專案根目錄的 `推送到GitHub.bat`，它會把本資料夾同步到 GitHub Pages repo 並推送（2026-10-24 起不再產生部署 ZIP）。手動上載時，把本資料夾的 index.html、core.js、pwa.js、sw.js、season.js、manifest.webmanifest，以及整個 icons 和 art 資料夾，一併放到原有 GitHub Pages 專案的發布目錄。core.js、season.js 和 art 資料夾（144 張 WebP）都不能遺漏，因為 Service Worker 安裝時會快取全部檔案，少一個就會安裝失敗。保留原網址與原路徑，避免切換到另一個儲存環境。

GitHub repository 的 Settings → Pages 可選擇發布分支及根目錄。程式使用相對路徑，支援 https://帳號.github.io/專案名稱/ 類型的網址。此交付只包含檔案，沒有代替你更新線上網站。

已安裝舊版的用家，請在有網絡時開啟原網址，等待新版檔案下載。舊版的更新按鈕仍在頁腳；更新後相關入口在每頁底部狀態列，以及貼紙簿頁底部的「備份與設定」。確認「更新至新版本」會重新載入；已保存帳目保留，尚未按「記一筆」或「儲存修改」的輸入不會保留。不要為了更新而清除網站資料。

## 資料相容與備份

沿用 lvtie.v1 本機儲存鍵，不會主動清除舊帳。舊帳目缺少固定日期時，第一次載入會依裝置當時的本地時區，從原時間戳推導日期；之後新記錄或保存過的記錄使用明確 date，不會因轉換時區而跳到另一記帳日。時間顯示仍隨裝置時區調整，「今天」亦跟隨裝置日期。

貼紙簿頁底部的「備份與設定」提供 JSON 匯出、JSON 合併匯入和 CSV 匯出。JSON 包含全部旅程、帳目、行程備註、預算與匯率；CSV 是逐筆帳目試算表，不可用來還原。匯出後請自行確認檔案已儲存，備份沒有密碼或加密，應妥善保管。

匯入先驗證格式，再顯示確認畫面。相同內容略過；同 ID 但內容不同的旅程以另一個 ID 保存為副本，不覆蓋原有旅程。這是整趟旅程層級的合併，不是逐筆自動同步；衝突副本需要用家自行核對。匯入限制為 50 MB、1,000 趟旅程及總共 100,000 筆記錄。一般儲存配額通常先於這些上限用盡。完整寫入本機儲存成功後才採用合併結果，失敗時原有帳目不變。

本機儲存失敗會顯示警告，請在關閉前匯出記憶體中尚可讀取的資料。如果原有 JSON 已損壞而無法讀取，程式會停止覆寫，並提供原始資料匯出；不會用空白帳本蓋掉原始檔。

「申請持久儲存」由瀏覽器決定是否批准，也有瀏覽器不支援。即使獲批准，手動清除網站資料、移除瀏覽器或換裝置仍可能失去帳目；它不能代替備份。

## 記帳、日期與預算

未出發的行程也可按「記錄行前支出」。記帳頁可直接選日期，支援旅程前後日期；補記非今日帳目時，時間預設為本地中午 12:00，可點擊記錄修改。可修改金額、收支類型、分類、日期、時間及備註；刪除後仍可立即復原。

修改旅程日期若有帳目落在新範圍以外，會先要求確認。確認後保留原日期，不自動搬移或刪除帳目。總覽與貼紙詳情會分別標示「行前支出」及「回程後記錄」，所有日期的收入、支出、分類與全旅程累計使用一致資料。

總預算按全部支出計算，不以收入抵銷；每日預算只適用於旅程日期內。旅途中日均支出＝旅程日期內支出 ÷ 完整旅程天數，行前與回程後支出不計入日均。進行中的預估總支出屬簡單推算：以截至今天的旅途中支出估算剩餘日數，並至少計入已記錄的未來支出；今天未結束或帳目未齊時可能不準確。

新建及修改後的旅程仍限制最多 120 天。為兼容原版可經修改產生的超長旅程，新版可讀取這類舊資料；只列出最初 120 天的空白日，加上所有有帳目或行程備註的日子，並清楚標示。統計仍包含全部帳目，日均使用完整旅程天數。

在行程頁可設定「1 當地幣＝多少 HKD」的手動匯率。港幣數字只供參考，不改動原幣記錄、不是即時匯率，也不包含信用卡手續費。更新匯率會重算整趟旅程的參考值，不是每筆鎖定交易匯率。留空即可停止換算。

## 介面調整

記帳頁縮短頂部摘要、把行程與預算細節移到鍵盤後方，數字鍵保持至少 44px。分類切換不再重繪整個頁面。收支總覽可選擇不同旅程，包括未出發、逾期及已完結旅程；加入預算進度、可展開的分類、只有支出時的簡潔版面，以及「前往今天」。

逾期提示可選「明天再提醒」，延期時間保存 24 小時，重新載入後仍有效。重新開啟已完結旅程也會暫緩提示。彈出層會鎖定背景捲動並限制鍵盤焦點。

## 離線使用

第一次請在 HTTPS 或 localhost 開啟，等每頁底部的狀態列顯示「已可離線使用」（綠點）。離線時狀態列變成橙點「離線模式 · 帳目照常保存在本機」，頁面頂部另有一個「離線中」提示；有新版本時頂部提示會附「更新」按鈕。「備份與設定」（匯出、匯入、持續儲存、完整離線資訊）已從旅程頁移到貼紙簿頁底部。離線快取包含新增的 core.js，使用同一版整套程式檔。直接雙擊本機 HTML 可供基本查看，但不會安裝 Service Worker，不能當成離線驗收。

iPhone／iPad 用 Safari 開啟並選「分享 → 加入主畫面」；其他支援瀏覽器可使用安裝提示。不同瀏覽器、裝置或安裝環境不保證共用帳目，移轉請使用 JSON 備份。日後修改程式時，請再次提升 sw.js 的 VERSION 並一起部署全部檔案。
