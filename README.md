# 旅貼 — 核心改善版

版本：2026-11-02-locale-1（前一版 feedback-1）。這一版由 2026-10-23-core-2（P0＋P1）加上「日本復古示範版」（lvtie-japan-retro）的全部改動組成，當時兩個資料夾的程式檔現在相同。新增的功能有：24 國國家／幣別、自填地方、各國景點卡片（每國 3 個景點 × 日景／夜景，共 144 張 WebP）、季節徽章、建立旅程時左右滑動選代表圖、離線狀態列，以及把「備份與設定」移到貼紙簿頁。修改前的 core-2 完整備份在 `agent-state/app-backup/lvtie-updated_pre-port_20261024113605/`。

圖片審核狀態：144 張中，各國第 1 個景點的日景／夜景（48 張）已經由使用者審核通過；第 2、3 個景點（96 張）只通過程式的數值檢查，還沒有經過使用者審核。

各版本的改動紀錄如下，越新的越前面。

## 2026-11-02 簡體中文、按手機語言／地區自動設定、參考貨幣可改、SEO（版本 2026-11-02-locale-1）

使用者問「能否讀取用家的手機語言及地區設定使第一次打開時便能設定為相對的語言及幣種」，選了「新增簡中」和「按地區自動，⚙可改」；之後又說「設定頁最後項的donate重複了,不用留。然後讓search engine能搜索到」。修改前的備份在 `agent-state/app-backup/lvtie-updated_pre-locale_202611021337/`。

語言：介面變成繁中、简体、English 三種。簡體不另寫一份字串，而是由 `i18n.js` 的 `LvtieHans()` 從繁中自動轉換：先套詞組表 PH（長的先換，例如「峇里島」），再按單字對照表 T2S 逐字換。第一次打開時只看瀏覽器的第一個偏好語言：zh-Hans 開頭的用简体；zh-Hant、香港、台灣、澳門用繁中；其他中文用简体；非中文用 English。使用者在 ⚙ 手動選過就記在 `lvtie.lang`，以後不再自動判斷。

參考貨幣：以前固定換算成港幣，現在每個旅程有自己的 `t.ref`。舊旅程沒有 `ref` 就當作 HKD，所以舊帳目不會變；`ref` 是空字串代表不換算。`t.hkdRate` 保留舊名字，但意思改成「1 單位當地貨幣等於多少參考貨幣」。全域設定記在 `lvtie.refCur`（ISO 代碼或 none）。第一次打開時 `guessRef` 先看時區，猜不到再看語言裡的地區。在 ⚙「參考貨幣」改選時，`adoptRef` 只會改還沒有自己輸入匯率的旅程。CSV 匯出加了參考貨幣欄。

設定頁：底部重複的贊助區塊拿掉了，贊助只留在語言下方的「支持與回饋」。

搜尋引擎：新增 `robots.txt` 和 `sitemap.xml`；`index.html` 加了 canonical（https://lvtie.vercel.app/）、中英標題與 description、Open Graph／Twitter 分享預覽和 JSON-LD（WebApplication）。使用者要自己做的 Search Console／Bing 步驟寫在根目錄的 `讓搜尋引擎找到旅貼.md`。

驗證：art 26、core 29×2（香港、紐約）、runtime 44×2、i18n 44、hans 44（新增 `dev/test_hans.js`，掃描所有畫面有沒有漏轉的繁體字）、SW 7、pwa_line 5、feedback worker 12。代測共 57 情境、29 頁，截圖看過 p21、p22、p28、p29。截圖時發現「參考貨幣」轉成「参考貨幣」，原因是 T2S 漏了「貨」，已補上並重新掃描全部檔案。簡體只是逐字加詞組表的轉換，不是人工翻譯；也不是真機驗收。

- 備份提醒：設定頁「把旅程帶走」顯示上次匯出 JSON 的時間（存在 localStorage `lvtie.lastBackup`）。完結旅程的畫面，如果最後一筆帳比上次備份新，會在「收進貼紙簿」下方顯示一句提示和「匯出 JSON 備份」按鈕。不會彈窗。

## 2026-10-30 試用修正四項＋英語介面（版本 2026-10-30-i18n-1）

## 資料相容與備份

沿用 lvtie.v1 本機儲存鍵，不會主動清除舊帳。舊帳目缺少固定日期時，第一次載入會依裝置當時的本地時區，從原時間戳推導日期；之後新記錄或保存過的記錄使用明確 date，不會因轉換時區而跳到另一記帳日。時間顯示仍隨裝置時區調整，「今天」亦跟隨裝置日期。

貼紙簿頁底部的「備份與設定」提供 JSON 匯出、JSON 合併匯入和 CSV 匯出。JSON 包含全部旅程、帳目、行程備註、預算與匯率；CSV 是逐筆帳目試算表，不可用來還原。匯出後請自行確認檔案已儲存，備份沒有密碼或加密，應妥善保管。

匯入先驗證格式，再顯示確認畫面。相同內容略過；同 ID 但內容不同的旅程以另一個 ID 保存為副本，不覆蓋原有旅程。這是整趟旅程層級的合併，不是逐筆自動同步；衝突副本需要用家自行核對。匯入限制為 50 MB、1,000 趟旅程及總共 100,000 筆記錄。一般儲存配額通常先於這些上限用盡。完整寫入本機儲存成功後才採用合併結果，失敗時原有帳目不變。

本機儲存失敗會顯示警告，請在關閉前匯出記憶體中尚可讀取的資料。如果原有 JSON 已損壞而無法讀取，程式會停止覆寫，並提供原始資料匯出；不會用空白帳本蓋掉原始檔。

「申請持久儲存」由瀏覽器決定是否批准，也有瀏覽器不支援。即使獲批准，手動清除網站資料、移除瀏覽器或換裝置仍可能失去帳目；它不能代替備份。

## 記帳、日期與預算

未出發的行程也可按「記錄行前支出」。記帳頁可直接選日期，支援旅程前後日期；補記非今日帳目時，時間預設為本地中午 12:00，可點擊記錄修改。可修改金額、收支類型、分類、日期、時間及備註；刪除後仍可立即復原。

修改旅程日期若有帳目落在新範圍以外，會先要求確認。確認後保留原日期，不自動搬移或刪除帳目。總覽與貼紙詳情會分別標示「行前支出」及「回程後記錄」，所有日期的收入、支出、分類與全旅程累計使用一致資料。

總預算按全部支出計算，不以收入抵銷；每日預算只適用於旅程日期內。旅途中日均支出＝旅程日期內支出 ÷ 完整旅程天數，行前與回程後支出不計入日均。進行中的預估總支出屬簡單推算：以截至今天的旅途中支出估算剩餘日數，並至少計入已記錄的未來支出；今天未結束或帳目未齊時可能不準確。

新建及修改後的旅程仍限制最多 120 天。為兼容原版可經修改產生的超長旅程，新版可讀取這類舊資料；只列出最初 120 天的空白日，加上所有有帳目或行程備註的日子，並清楚標示。統計仍包含全部帳目，日均使用完整旅程天數。

在行程頁可設定「1 當地幣＝多少 HKD」的手動匯率。港幣數字只供參考，不改動原幣記錄、不是即時匯率，也不包含信用卡手續費。更新匯率會重算整趟旅程的參考值，不是每筆鎖定交易匯率。留空即可停止換算。
